# 덕소 사회복무요원 근무표 생성기

Streamlit과 OR-Tools CP-SAT으로 월간 사회복무요원 근무표를 생성하고 저장하는 앱입니다.

## 설치

```cmd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 실행

```cmd
streamlit run app.py
```

## 데이터 파일

- 요원 목록: `data/agents.json`
- 설정값: `data/settings.json`
- 생성된 월별 근무표: `data/schedules/YYYY-MM.json`

## 근무 코드

- `D`: 주간
- `N`: 야간
- `R`: 비번
- `O`: 휴무
- `X`: 비활성 또는 표시 제외

## 요원 유형

- 일반: 주간, 야간, 비번, 휴무 배치 가능
- 주간 전담: 야간과 비번 배치 불가
- 야간 전담: 주간 배치 불가

복무 중(`active=true`)인 요원만 근무표 생성 대상입니다. 생성 시 요원은 관리번호 순으로 정렬되고, 그 순서가 숙련 서열로 사용됩니다.

## 실제 생성 규칙

### 필수 조건

- 복무 중 요원이 최소 4명 이상이어야 합니다.
- 각 요원은 하루에 `D`, `N`, `R`, `O` 중 정확히 하나만 배정됩니다.
- 매일 야간은 최소 1명, 최대 2명입니다.
- 매일 주간은 최소 1명입니다.
- 각 요원의 월 휴무(`O`) 개수는 해당 월의 휴일 수와 정확히 같아야 합니다.
- 휴일 수는 토요일, 일요일, 그리고 `holidays` 패키지가 인식하는 한국 공휴일을 합산합니다.
- 야간 근무 다음 날은 반드시 비번(`R`)입니다.
- 야간 근무 이틀 뒤가 같은 달 안에 있으면 반드시 휴무(`O`)입니다.
- 비번(`R`)은 전날 야간(`N`)이 있어야만 배정됩니다.
- 전달 마지막 날 야간자는 이번 달 1일 비번, 2일 휴무로 이어집니다.
- 전달 마지막 전날 야간자는 이번 달 1일 휴무로 이어집니다.
- 예비군 미수료(`pre_service=true`) 또는 교육 미수료(`training_completed=false`) 요원은 같은 날 야간에 2명 이상 배치되지 않습니다.
- 같은 제한 요원 그룹은 같은 날 주간에도 2명 이상 배치되지 않습니다.

### 목표 인원

기본 설정값은 다음과 같습니다.

- 평일 주간 목표: 2명
- 휴일 주간 목표: 2명
- 평일 야간 목표: 2명
- 휴일 야간 목표: 2명

금요일, 토요일, 일요일, 공휴일은 휴일/혼잡일 기준 목표를 사용합니다. 그 외 날짜는 평일 기준 목표를 사용합니다.

목표 인원은 강제 조건이 아니라 최적화 목표입니다. 조건 충돌이 있으면 목표에서 벗어날 수 있지만, 야간 1~2명과 주간 최소 1명 같은 필수 조건은 지켜야 합니다.

### 최적화 우선순위

생성기는 가능한 근무표 중 벌점이 낮은 배치를 선택합니다. 코드상 벌점이 큰 항목일수록 더 강하게 피합니다.

- 야간 목표 인원 미달 또는 초과를 강하게 피합니다.
- 주간 목표 인원 미달 또는 초과를 피합니다.
- 주간이 1명뿐인 날을 강하게 피합니다.
- 주간 4명 이상 배치는 매우 강하게 피합니다.
- 주간 5명 이상 배치는 사실상 최우선으로 피합니다.
- 야간 1명인 날은 피하되, 월 2일까지는 상대적으로 허용합니다.
- 목표보다 주간 인원이 많은 날은 피합니다. 특히 월 3일을 넘으면 강하게 피합니다.
- 요원별 전체 근무 횟수와 야간 횟수가 고르게 분산되도록 합니다.
- 날짜별 휴무 인원이 고르게 분산되도록 합니다.
- 야간 전날에 주간이 오도록 선호합니다.
- 단독 휴무, 즉 앞뒤가 휴무가 아닌 하루짜리 휴무를 피합니다.
- 숙련 서열 차이가 2 이하인 요원끼리 같은 날 야간에 들어가는 것을 약하게 피합니다.

### 주간 전담 추가 규칙

주간 전담 요원은 별도 선호 규칙을 더 받습니다.

- 금요일~일요일 3일이 모두 같은 달에 있으면 그중 최소 2일은 휴무가 되도록 강제합니다.
- 금요일, 토요일, 일요일, 공휴일에는 주간 배치를 피합니다.
- 평일에는 휴무 배치를 피합니다.
- 단독 휴무를 일반 요원보다 강하게 피합니다.

## 설정 화면과 현재 코드의 차이

아래 설정값은 저장되지만, 현재 `core/scheduler.py`의 생성 로직에서는 실제로 사용되지 않거나 화면 설명과 다르게 동작합니다.

- `max_consecutive_work_days`: 저장만 되고 연속 근무 제한에 사용되지 않습니다.
- `night_rest_required`: 설정값과 무관하게 야간 다음 날 비번은 항상 강제됩니다.
- `prefer_off_after_rest`: 설정값과 무관하게 야간 이틀 뒤 휴무는 항상 강제됩니다.
- `senior_pair_rank_limit`: 설정값은 사용되지 않습니다. 실제 코드는 서열 차이 2 이하의 같은 날 야간만 약한 벌점으로 처리합니다.
- `avoid_regular_agent_pair`: 저장만 되고 일반 요원끼리 야간 동시 배치 금지에는 사용되지 않습니다.

## 생성 실패가 날 수 있는 경우

- 복무 중 요원이 4명 미만인 경우
- 주간 가능 인원이 설정된 주간 목표보다 적은 경우
- 야간 가능 인원이 2명 미만인 경우
- 전달 근무표에서 이어지는 비번/휴무 조건과 이번 달 조건이 충돌하는 경우
- 모든 요원의 월 휴무 개수를 휴일 수와 정확히 맞출 수 없는 경우

## 개발 메모

스케줄 생성의 실제 기준은 `core/scheduler.py`입니다. README의 규칙 설명은 설정 화면 문구가 아니라 이 파일의 제약식과 벌점식을 기준으로 정리했습니다.
